CSV 파일을 불러와 주세요.
  • CSV 파일을 불러오면 검색할 수 있습니다.
이 페이지는 어떻게 만들었나요?

서버 없는 정적 웹페이지로 만든 이유

  • HTML 파일 하나에 모든 처리 코드가 들어 있어 서버·DB 없이 동작하고, 정적 호스팅(GitHub Pages 등)에 올려도 됩니다.
  • CSV 읽기와 검색을 전부 브라우저가 하므로 파일이 외부로 전송되지 않습니다. 보안 정책(CSP)으로 네트워크 전송 자체를 차단해 두었습니다. 지도 타일 요청에는 화면 위치(타일 번호)만 포함되고 CSV 내용은 포함되지 않습니다.

지도 라이브러리와 베이스맵의 차이

  • 라이브러리(Leaflet): 지도 화면과 확대/축소, 마커를 다루는 프로그램입니다.
  • 베이스맵(타일): 배경이 되는 지도 이미지 조각입니다. OSM, CARTO, Esri 등이 무료로 공개합니다.
  • Leaflet이 고른 베이스맵 타일을 불러오고 그 위에 검색된 업소를 그립니다. 일부 타일 서버가 막혀도 자동으로 Esri 도로 지도로 전환합니다.

대용량 CSV 성능

  • 파일 해석은 백그라운드 스레드(Web Worker)에서 조각 단위로 처리하고, 필요한 값만 메모리에 보관합니다.
  • 마커는 개별 객체를 만들지 않고 캔버스 한 장에 직접 그립니다. 화면에 보이는 업소가 많으면 격자로 묶어 개수만 표시하고, 누르면 확대됩니다.
  • 검색은 입력 후 0.25초 뒤에 실행하며, 목록은 200건씩 나눠 보여줍니다.

마커 설정을 크기만 둔 이유

  • 업소 수에 따라 작게/크게 보고 싶은 수요가 실제로 있어 크기 조절은 넣었습니다.
  • 종류(모양·아이콘) 선택은 업종 구분 같은 의미가 없으면 정보가 늘지 않고, 대량 렌더링 성능과 모바일 화면 복잡도만 늘어 뺐습니다.
