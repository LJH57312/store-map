# 상가업소 검색 지도

상가업소 CSV 파일을 불러와 **검색 → 지도 표시 → 검색 결과 저장**까지 할 수 있는 무료 웹페이지입니다.
설치도 가입도 필요 없고, 불러온 CSV는 **내 브라우저 안에서만** 처리되어 어디로도 전송되지 않습니다.

## 바로 사용하기

**https://내사용자이름.github.io/저장소이름/**

> 위 주소는 예시입니다. 저장소 주인은 실제 주소로 바꿔 주세요. (방법은 `GitHub_배포가이드.md` 참고)

PC와 휴대폰 브라우저 모두에서 사용할 수 있습니다.

## 사용 방법

1. 위 주소로 접속합니다.
2. 왼쪽 위 **CSV 파일 선택** 칸을 누르거나, CSV 파일을 끌어다 놓습니다. (휴대폰에서는 칸을 눌러 파일 선택)
3. 검색창에 상호명, 지점명, 도로명 중 일부를 입력합니다. 띄어쓰기로 단어를 여러 개 넣으면 모두 포함된 곳만 나옵니다.
4. 목록과 지도에 결과가 나타납니다. 마커를 누르면 상호명·지점명·도로명이 보입니다.
5. **GeoJSON 저장** 또는 **CSV 저장**을 누르면 현재 검색된 결과만 파일로 저장됩니다.

배경지도(일반 / 밝은 단순 / 위성)와 마커 크기는 왼쪽 패널에서 바꿀 수 있습니다.

## CSV 파일 조건

아래 5개 열 이름이 **반드시** 있어야 합니다.

| 필수 열 | 인식되는 이름 |
|---|---|
| 상호명 | `상호명` |
| 지점명 | `지점명` |
| 경도 | `경도`, `lon`, `lng`, `longitude` |
| 위도 | `위도`, `lat`, `latitude` |
| 도로명 | `도로명`, `도로명주소`, `도로명 주소` |

- 열이 없으면 화면 위에 어떤 열이 없는지 알려 주고, 기존 화면은 그대로 유지됩니다.
- 일부 행의 좌표가 비어 있으면 그 행은 목록에만 나오고 지도에는 표시되지 않습니다.
- `.csv` 파일만 사용할 수 있습니다. UTF-8, EUC-KR(CP949) 인코딩은 자동으로 구분합니다.

## 개인정보와 보안

- CSV 내용은 서버로 전송되지 않습니다. 모든 처리는 사용자의 브라우저 안에서만 이루어집니다.
- 페이지에 보안 정책(CSP)을 걸어 데이터 전송(fetch/XHR 등) 자체를 브라우저가 차단하도록 했습니다.
- 지도 배경 이미지를 받아올 때는 "지도의 어느 부분을 보는지"만 지도 서버에 전달됩니다.

## 자주 묻는 질문

**지도가 회색이거나 비어 있어요.**
인터넷 연결을 확인하고 배경지도를 다른 종류로 바꿔 보세요. 선택한 지도가 계속 실패하면 자동으로 다른 지도로 전환됩니다.

**파일을 올렸는데 "형식이 달라" 오류가 나와요.**
`.csv` 파일인지 확인하세요. 엑셀(`.xlsx`)은 "다른 이름으로 저장 → CSV"로 바꿔서 사용합니다.

**데이터가 아주 많으면 느린가요?**
수십만 건도 처리하도록 만들었습니다. 파일을 읽는 동안 상태줄에 건수가 올라갑니다. 지도에서는 가까운 업소를 숫자 원으로 묶어 보여주고, 누르면 확대됩니다.
